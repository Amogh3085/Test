# Calculator App

A beautiful, modern, and user-friendly calculator built with HTML, CSS, and JavaScript.

## Features

### 🎨 Modern Design
- Beautiful gradient background with glassmorphism effect
- Smooth animations and hover effects
- Responsive design that works on all devices
- Clean, intuitive interface

### 🧮 Calculator Functions
- **Basic Operations**: Addition (+), Subtraction (-), Multiplication (×), Division (/)
- **Clear Functions**: 
  - AC (All Clear) - Resets everything
  - DEL (Delete) - Removes last entered digit
- **Decimal Support**: Full decimal number support
- **Error Handling**: Prevents division by zero with user-friendly alerts
- **Number Formatting**: Large numbers display with thousand separators

### ⌨️ Keyboard Support
- **Numbers**: 0-9 keys
- **Operations**: +, -, *, / keys
- **Actions**:
  - Enter or = : Calculate result
  - Backspace: Delete last digit
  - Escape: Clear all
  - Decimal point: . key

### 📱 User Experience
- **Visual Feedback**: Buttons animate when pressed (both mouse and keyboard)
- **Continuous Operations**: Chain multiple operations together
- **Previous Operation Display**: Shows your calculation history
- **Responsive Layout**: Adapts to different screen sizes
- **Touch-Friendly**: Large buttons for mobile devices

## How to Use

### Getting Started
1. Open `index.html` in any modern web browser
2. Start calculating immediately!

### Basic Operations
1. **Enter numbers** by clicking buttons or using your keyboard
2. **Choose an operation** (+, -, ×, /) 
3. **Enter the second number**
4. **Press = or Enter** to see the result

### Advanced Usage
- **Chain calculations**: After getting a result, immediately use an operator to continue calculating
- **Quick corrections**: Use DEL to remove the last digit, or AC to start over
- **Keyboard shortcuts**: Use your keyboard for faster input

### Example Calculations
```
15 + 25 = 40
100 - 30 = 70
12 × 8 = 96
144 ÷ 12 = 12
```
